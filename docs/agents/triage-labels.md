# Triage labels

| Papel canônico | Label no GitHub | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Precisa de avaliação do mantenedor |
| needs-info | needs-info | Aguarda informações do autor |
| ready-for-agent | ready-for-agent | Especificada e pronta para um agente |
| ready-for-human | ready-for-human | Requer implementação humana |
| wontfix | wontfix | Não será implementada |

Quando uma skill mencionar um papel, usar o label correspondente.
Editar a segunda coluna caso o vocabulário do projeto mude.
